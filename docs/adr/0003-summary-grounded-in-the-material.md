# 0003 — The Summary is strictly grounded in the Material

The Summary uses only the text of the Material that was read. It brings no
external knowledge, does not fill gaps and states explicitly when something is
not covered. Every point is tied to the section it came from.

This is a trust decision, not a quality one. The listener studies for an exam,
and a Summary that "explains better" by inventing context produces a confident
error, which is the worst failure mode for academic material. The didactic value
comes from selection, ordering and spoken prose, not from new content.

**Consequences:** the Summary is drier than a generated lecture and can
disappoint someone expecting analogies. In exchange, everything it claims is
verifiable in the Material. The prompt must be tested against real material to
confirm that the refusal appears when the question leaves the text.
